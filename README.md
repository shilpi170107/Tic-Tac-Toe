# 🎮 Tic Tac Toe Game

A fun and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**. Two players can play together by taking turns marking X and O.

## ✨ Features

- Two-player gameplay
- Automatic winner detection
- Draw detection
- Reset button to start a new game

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
